# Multi-Tool AI Agent مع Ollama

Agent يعمل محليًا عبر Ollama (نموذج `llama3.2:3b`) ويقرر **بنفسه** أي أداة يستخدم
من بين ثلاث أدوات، حسب سؤال المستخدم.

## الأدوات (Tool Registry)

| الأداة | الوظيفة | الدالة |
|--------|---------|--------|
| `CALCULATOR` | أي عملية حسابية | `calculator_tool(expression)` |
| `SEARCH_FILE` | بحث عن معلومة عن الشركة في ملف نصي | `search_file_tool(keyword)` |
| `READ_DATA` | سعر/كمية منتج من جدول CSV | `read_data_tool(product_name)` |

## الملفات

- `part1_design.md` — تصميم صندوق الأدوات + الـ Prompt الشامل.
- `agent_tools.py` — الأدوات الثلاث + دالة `route_and_respond()` + كل الاختبارات.
- `company_info.txt` — بيانات شركة وهمية (لأداة البحث).
- `products.csv` — 8 منتجات (لأداة قراءة البيانات).
- `screenshots/` — لقطات لتشغيل فعلي.

## التشغيل

```bash
pip install requests pandas
ollama pull llama3.2:3b
python agent_tools.py
```

## نتائج الاختبار (كلها نجحت فعليًا)

- **الحاسبة:** `340*12=4080`، والقسمة على صفر تُرجع رسالة خطأ واضحة بدل التعطل.
- **البحث بالملف:** الكلمات "التأسيس/الموظفين/الخدمات" تُرجع الأسطر الصحيحة.
- **قراءة المنتجات:** "لابتوب/ماوس/شاشة" تُرجع السعر والكمية، و"تلفزيون" (غير موجود)
  يُرجع رسالة واضحة.
- **الـ Agent الكامل (6 أسئلة):** اختار الأداة **الصحيحة في كل الأسئلة**
  (سؤالان لكل أداة) وصاغ أجوبة طبيعية صحيحة:
  | السؤال | الأداة المختارة | صحيح؟ |
  |--------|------------------|-------|
  | كم ناتج 340 ضرب 12؟ | CALCULATOR | ✅ |
  | لو وزعت 1500 على 7؟ | CALCULATOR | ✅ |
  | وين مقر الشركة؟ | SEARCH_FILE | ✅ |
  | كم عدد الموظفين؟ | SEARCH_FILE | ✅ |
  | كم سعر الماوس؟ | READ_DATA | ✅ |
  | كم المتوفر من اللابتوب؟ | READ_DATA | ✅ |

### ملاحظة عن ضبط الـ Prompt
لجعل اختيار الأداة دقيقًا، طُلب من النموذج كتابة **سطر واحد فقط** بصيغة
`TOOL: input` (مع `stop` عند نهاية السطر و`temperature=0`)، مما منع الخلط بين
الأدوات وجعل الاختيار صحيحًا 100% في الاختبارات الستة.
